# BMI Calculator 🧮

## 📌 Project Description
The BMI Calculator is a simple Python application that calculates Body Mass Index (BMI) using a person's weight and height.

## ✨ Features
- Accepts weight in kilograms.
- Accepts height in metres.
- Calculates BMI using the standard formula.
- Displays a general adult BMI category.
- Handles invalid numeric input.
- Rejects zero and negative values.

## 🛠️ Technologies Used
- Python 3
- Visual Studio Code

## 📐 BMI Formula
BMI = Weight (kg) / Height (m)²

## ▶️ How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command in the terminal:

   python bmi.py

5. Enter your weight in kilograms.
6. Enter your height in metres.
7. View your BMI result and category.

## 💻 Sample Output
Weight: 60 kg
Height: 1.6 metres
BMI: 23.44
Category: Normal weight
