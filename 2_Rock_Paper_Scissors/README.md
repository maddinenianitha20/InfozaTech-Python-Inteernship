Rock, Paper, Scissors Game 🎮

Project Description

This is a simple Python game where the user plays Rock, Paper, Scissors against the computer.

Features 

- User can choose Rock, Paper, or Scissors.
- Computer randomly selects an option.
- The program determines the winner using game rules.
- Tracks the user's score, computer's score, and draws.
- Supports multiple rounds.
- Displays the final score when the user exits the game.

Technologies Used

- Python
- Random module
- While loop
- Conditional statements

How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

python rock_paper_scissors.py

How to Play

1. Enter "rock", "paper", or "scissors".
2. The computer randomly selects its choice.
3. Check the result and current score.
4. Continue playing multiple rounds.
5. Enter "exit" to finish and see the final score.
