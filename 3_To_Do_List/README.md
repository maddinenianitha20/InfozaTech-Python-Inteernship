# 📝 To-Do List Application Using Python

## 📌 Project Overview

The To-Do List Application is a simple command-line application
developed using Python to help users manage their daily tasks.

Users can add tasks, view their task list, mark tasks as completed,
remove tasks, and organize tasks based on priority or due date.

The application stores tasks in a JSON file so that saved tasks
remain available when the program is run again.

## ✨ Features

1. **Add Tasks:** Add a task with a description, due date, and priority.
2. **View Tasks:** Display tasks with their numbers and completion status.
3. **Complete Tasks:** Mark pending tasks as completed.
4. **Remove Tasks:** Delete tasks from the list.
5. **Save Tasks:** Store tasks in a JSON file.
6. **Prevent Duplicates:** Avoid adding tasks with duplicate descriptions.
7. **Priority Management:** Assign High, Medium, or Low priority.
8. **Sort Tasks:** Organize tasks by priority or due date.
9. **Input Validation:** Handle invalid dates, priorities, and task numbers.

## ▶️ How to Run the Project

### Step 1: Install Python

Install Python on your computer if it is not already installed.

### Step 2: Open the Project

Open the project folder in Visual Studio Code.

### Step 3: Open the Terminal

Open the terminal inside Visual Studio Code.

### Step 4: Run the Application

Execute the following command:

python todo_list.py

If necessary, use:

py todo_list.py

### Step 5: Use the Application

Choose an option from the menu to add, view, complete, remove,
or sort tasks.
